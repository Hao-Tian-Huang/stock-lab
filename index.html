模型和策略，各自負責什麼？

Python 的 TCN 提取20日價量特徵，再交給隨機森林預測下一交易日開盤至再下一交易日開盤的報酬。網頁讀取這些預測，只在週二訊號後安排週三買、週四賣。

改變模型架構、特徵或訓練期間，需回到 Colab 重訓。本頁更改的是選股門檻、資金與交易成本。

回測的計算假設

  • 使用調整後日線與連續比例部位，不是實際股數。
  • 買入預算含手續費；卖出扣手續費與交易稅。
  • 開盤加滑價高於週二收盤價的指定上限，當週不買該股。
  • 已買進卻缺少出場行情會停止回測，不事後刪除虧損。
  • 不模擬最低手續費、零股、股息入帳日及開盤撮合排隊。

如何解讀四個數字？

總報酬：期末資產相對初始資金的變化。
年化報酬：按實際經過日數換算複利，短期結果可能不穩定。
夏普比率：每日淨值報酬平均 ÷ 樣本標準差 × √252；預設無風險利率0。
最大回撤：每日收盤淨值從歷史高點下跌的最大比例，不含盤中跌幅。

資料與可重現性

示範模式完全使用合成行情。內建的12週實測摘要來自你提供的Colab輸出，沒有編造其每日資產曲線。匯入完整資料後才繪製與重算你的實際回測。

固定股票池可能包含事後選股偏差；臺灣50名單也必須標記日期。已看過並用來調參的12週是開發期間，不能再視為全新的測試。

本機檔案與隱私

「研究檔案」是這台裝置瀏覽器中的個人設定，不是真正帳號登入，沒有密碼或跨裝置同步。策略版本保存在 localStorage；清除瀏覽器資料可能刪除紀錄，請匯出備份。

此檔不需要外部 JavaScript 或 CSS，能離線開啟。選股清單中的名稱僅作識別，匯入的股票代號為準。
